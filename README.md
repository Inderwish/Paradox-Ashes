# 悖论的灰烬：冰层之下

**Paradox Ashes: Beneath the Ice** · v5.8 Enhanced

> *"这是一个关于极速的空转的故事。"*

一个沉浸式交互叙事网页作品，融合程序化视觉特效、实时合成音乐与多章节叙事，讲述一个同时掌握了极致效率与极致浪漫的文明在自身矛盾中"过热宕机"的故事。

---

## ✨ 特性

| 类别 | 描述 |
|------|------|
| **多章节叙事** | 6 个风格迥异的章节，各自拥有独立的视觉主题与交互方式 |
| **程序化音频** | 基于 Web Audio API 的实时 Synthwave 音乐合成，无需加载外部音频文件 |
| **WebGL 冰层** | 使用 GLSL Fragment Shader 渲染的冰层探索场景（FBM 噪声 + 动态裂纹） |
| **Canvas 粒子系统** | 对象池驱动的高性能粒子效果：雨滴代码、雪花、余烬、列车都市等 |
| **交互装置** | 加密文字解密、终端日志回放、光束审判动画、列车加速仪表盘、书架浏览 |
| **萤火虫氛围层** | 跨章节的半透明浮光粒子，随主题色平滑过渡 |
| **无障碍支持** | Skip link、`aria-*` 标注、键盘导航、`prefers-reduced-motion` 适配 |
| **响应式设计** | 移动端可收起侧边栏 + 桌面端双栏布局 |

## 🚀 快速开始

由于项目为纯静态页面，无需构建步骤：

1. **直接打开** — 在浏览器中打开 `index.html` 即可运行。
2. **本地服务器**（推荐）— 使用任意静态文件服务器避免 CORS 限制：
   ```bash
   # 使用 Python
   python -m http.server 8080

   # 或使用 Node.js
   npx serve .
   ```
3. 在浏览器中访问页面，点击 **"TOUCH TO INITIALIZE"** 启动系统。

## 🔧 技术栈

- **HTML5 / CSS3 / JavaScript**（原生，无框架）
- **Tailwind CSS**（CDN 引入，用于实用类布局）
- **Web Audio API** — 实时合成 Bass / Pad / Arp 音轨
- **WebGL (GLSL)** — 冰层 Shader 渲染
- **Canvas 2D** — 粒子系统、天际线生成、列车场景
- **Google Fonts** — Noto Serif SC · Space Mono · Playfair Display · Great Vibes · Ma Shan Zheng

## ⚡ 性能优化

- `ParticlePool` 对象池，减少 GC 压力
- `requestAnimationFrame` 帧率限制（120fps 上限）
- `prefers-reduced-motion` 媒体查询：自动关闭所有动画
- 音频节点定期清理，防止内存泄漏
- `will-change` 提示合成器层优化
- 标签页不可见时自动暂停音频引擎
